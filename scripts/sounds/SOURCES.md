# 効果音の出典

PVの効果音は、[Kenney](https://kenney.nl)の音源です。どちらもCC0(パブリックドメイン)で配布されています。

| ファイル                                                                                                                                              | 元の音源                    | 元のファイル   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | -------------- |
| `click_002.wav`、`click_003.wav`、`click_005.wav`、`maximize_004.wav`、`drop_004.wav`、`confirmation_002.wav`、`confirmation_004.wav`、`bong_001.wav` | Kenney Interface Sounds 1.0 | 同名のファイル |
| `ui_click1.wav`                                                                                                                                       | Kenney UI Audio(UI SFX Set) | `click1.wav`   |

取得元は、Godotのアセットライブラリに登録されている次のリポジトリです。

- [Calinou/kenney-interface-sounds](https://github.com/Calinou/kenney-interface-sounds)(コミット`4596a49`)
- [Calinou/kenney-ui-audio](https://github.com/Calinou/kenney-ui-audio)(コミット`8c3d81b`)

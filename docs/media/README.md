# 紹介動画

`ask-form-pv.mp4`は、Ask Formの紹介動画です。`pnpm media`で、実際のVS Codeを動かして作り直します。

GitHubはリポジトリに置いた動画をREADMEの中で再生しないため、今はREADMEからリンクしていません。GitHub Pagesで再生できるページを公開するまでの置き場所です。

## BGM

紹介動画のBGMには、次の曲を使っています。この曲はMITライセンスの対象外です。

- 曲名: Minimal Techno 01
- 作曲者: Alejandro Magaña
- 配布元: [Mixkit](https://mixkit.co/free-stock-music/tag/technology/)
- ライセンス: [Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree)

曲のファイルはリポジトリに入れていません。作り直すときは、配布元から曲を落として`scripts/music/`に置いてから、`pnpm media`を実行します。曲のファイルが無いと、BGMなしの動画になります。
